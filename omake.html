２章おまけ：変数

Arduinoのプログラム（C言語）には、変数という便利なしくみがあります。

変数とは「データに名前をつけて保存しておくための入れ物」です。

例えば、LEDをつないでいるピン番号を変数に入れておけば、プログラムの中でその名前を使ってLEDを操作できるようになります。

  • どのピンを使っているかが分かりやすくなる
  • 後でピン番号を変更したいときに、1か所変えるだけで済む
  • 数字だけよりも読みやすく、ミスも減る
変数をつくるときには「型」という種類を指定します。
型は「どんな種類のデータを入れる箱か」を表すものです。
ピン番号などの整数には int型 を使います。（ほかにも様々な型があります）

変数の使い方

変数を使うには、まず変数を宣言（せんげん）します。
宣言とは、「この名前の変数を使いますよ」とプログラムに伝えることです。

変数の宣言は、以下のように行います。

int ledPin = 7;

上の例では、int型の変数ledPinを宣言し、7という値を入れています。
これで、ledPinという名前を使って7番ピンを操作できるようになります。

３章おまけ：繰り返し処理

        

            
３章では、7セグメントLEDを制御するために８本のピンを使用しました。

            
これまでは、各ピンごとに１行ずつプログラムを書いて設定していましたが、繰り返し処理を使うことで、同じような処理をまとめて書くことができ、コードを短くすることができます。
            

            

                繰り返し処理を行うときには for文 を使います。

                for文を使うと、次のように記述できます。
                
for (初期化; 条件式; 更新処理) {
    繰り返し中に行う処理;
}

                
for文は「初期化 → 条件判定 → 処理 → 更新」を自動で繰り返してくれる構文です。

            

            

                実際に0～7番ピンをまとめて出力に設定する例
                
for (int i = 0; i < 8; i++) {
    pinMode(i, OUTPUT);
}

                
    
                    
  • int i = 0; …… 最初に i を 0 にする（スタート）
    • 
                    
  • i < 8; …… i が 8 より小さい間（0～7の間）繰り返す
    • 
                    
  • i++; …… 繰り返すたびに i の値を1増やす
    • 
                

            

            
このようにfor文を使うことで、7セグメントLEDのように複数のピンをまとめて設定するコードを、短くわかりやすく書くことができます。

３章おまけ２：配列(Array)

        
前のページでは、繰り返し処理（for文）を使うことで、同じ処理を短く書けることを学びました。

        
LEDの点灯の処理を行う際にも、配列という機能と、繰り返し処理を使うことで、コードを短くすることができます。


        

            
複数のピンをまとめて管理したいときは、配列（Array）が便利です。

            
    
                
  • ピン番号をひとまとめにできる
    • 
                
  • for文と組み合わせて、初期設定や点灯処理を簡単に記述できる
    • 
                
  • 後からピン番号を変更したい場合も、配列の中身だけ変えればOK
    • 
            

            

                配列の宣言例
                
int segPins[8] = {2, 3, 4, 5, 6, 7, 8, 9};

                
例：segPins[0]はピン2、segPins[1]はピン3…というようにアクセスできます。

            

            

                for文と組み合わせた初期設定
                
for (int i = 0; i < 8; i++) {
    pinMode(segPins[i], OUTPUT);
}

                
配列の各ピン番号を順番に取り出して、すべてOUTPUTに設定できます。

            

            
配列を使うことで、コードが短く・管理しやすくなります。

上のプログラムは、3番ピンを出力用として設定し、3番ピンをHIGHにするプログラムです。

        
3番ピンにLEDが接続されている場合、点灯するようになっています。

        
プログラムを書く上で重要なこと


        
セミコロン ( ; ) は必ず必要

        
命令文の最後には必ず セミコロン ( ; ) をつけます。これを忘れると「エラー」になって、プログラムが動きません。


        
pinMode(3, OUTPUT);
digitalWrite(3, HIGH);


        
波かっこ { } の役割

        
setup() と loop() の中身は、必ず { } で囲む必要があります。もし波かっこを消してしまうと、どこまでが
            setup の中なのかを Arduino が理解できず、エラーになります。
        


        
コメント ( // )

        
プログラムの中に説明を書いておくことができます。コメントはプログラムの動作には影響しません。


        
// 3番ピンを出力用にする
// 3番ピンをHIGHにする
