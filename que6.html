第７章　シリアルモニタ

この章ではシリアルモニタの使い方について学びます。

シリアルモニタとは、マイコンとコンピューター(マイコン同士も可能)との通信を利用したデータの送受信やデバッグ(プログラムの不具合を修正する作業)などに利用されるものです。

このように、シリアルモニタを使うことで、変数の値などプログラムの動作状況をリアルタイムで確認することができます。


    
シリアルモニタの使い方

    
    
      
  1. シリアル通信の準備
    
        マイコンとパソコン間でデータをやりとりする「シリアル通信」を使います。
      
    2. 
      
  2. プログラムで通信開始
    
        プログラムの中でSerial.begin()命令を書き、通信を開始します。
      
    3. 
      
  3. シリアルモニタに表示する
    
        Serial.println()を使うと、マイコンからパソコンへ文字や数値を送信し、シリアルモニタに表示できます。
      
    4. 
    

    


    

    
通信開始の命令例

    

      void setup() { Serial.begin(9600); // 通信速度を9600bpsに設定 }
    

    
    
      
  • Serial.begin()で通信速度（ボーレート）を指定します（例：9600bps）。
    • 
      
  • この命令はsetup()の中に1回だけ書きます。
    • 
      
  • その後、Serial.print()やSerial.println()でデータを表示できます。
    • 
      
  • Serial.print()は改行せずに表示し、Serial.println()は表示後に改行します。
    • 
    

    
注意：実際のエディタ(Arduino IDEなど)でシリアルモニタを使う場合、

      シリアルモニタ側の通信速度設定を、プログラムの値（例：9600）に合わせる必要があります。
